# Project-Tokopedia
Tokopedia transaction database design and SQL implementation using Oracle APEX.

## Project Overview

A database project based on Tokopedia's transaction process, focusing on database design and SQL implementation using Oracle APEX.

## Project Scope

The project focuses on the transaction process, including buyers, sellers, products, orders, order details, and payments. The project covers database structure and transaction logic. 

## Database Design

An Entity Relationship Diagram (ERD) was designed to represent the relationships between the main entities in the transaction system.

## SQL Implementation

The project includes:

- CREATE TABLE
- INSERT DATA
- UPDATE DATA
- SQL Views
- INNER JOIN
- OUTER JOIN
- UNION / UNION ALL
- INTERSECT
- MINUS
- Subqueries

## Tools

- Oracle APEX
- SQL
